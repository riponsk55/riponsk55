## About

This repository hosts the static HTML/CSS/JS source of the portfolio, originally built and published on Blogger (Blogspot) and mirrored here for version control and GitHub Pages hosting.

### Highlights
- **Telecom expertise**: Telecom power/infrastructure (rectifiers, batteries, generators, MDB/FCU), NTTN & ISP network support, fiber optic splicing, MikroTik configuration, OLT/ONU connectivity, Radius Manager billing.
- **Web development**: Responsive websites using HTML, CSS, JavaScript, and Tailwind CSS; WordPress & Blogspot customization.
- **Projects**: Roja Shop (eCommerce), DocBD.org (doctor listing directory).
- **Integrations**: Google Forms, Apps Script, Telegram Bot, WhatsApp notifications.

## Tech Stack
- HTML5, CSS3, JavaScript (vanilla)
- Tailwind CSS (CDN)
- Font Awesome icons
- Google Fonts (Hind Siliguri)
